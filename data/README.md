# Private data directory

Place the supplied Kestrel task pack in this directory before training:

- `train.csv`
- `test_unlabelled.csv`
- `partners.csv`
- `products.csv`
- `sample_submission.csv`

The supplied files contain client operational data and are intentionally excluded from Git. The trained model and `predictions.csv` are also excluded because they retain information derived from that data.
